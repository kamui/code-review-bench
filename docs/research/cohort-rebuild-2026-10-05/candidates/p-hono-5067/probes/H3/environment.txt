The framework has no runtime dependencies; its TypeScript source was imported directly (no install, no build of the framework).
How a probe runs (probes/run.sh): the probe is copied to <checkout>/_probe/probe.ts, run with
  bun run probe.ts
then bundled with
  bun build probe.ts --target=node --outfile=probe.node.mjs
and the bundle is run with node. So each result file holds a bun section and a node section.
Scratch directory (deleted after the runs): <scratch>/

  NODE_BIN=<node 24.7.0> probes/H3/capped.sh head <scratch>/head               > probes/H3/result-capped-head.txt
  node native-case.mjs; bun native-case.mjs                                    > probes/H3/result-native-case.txt
measure.sh starts a fresh process for every measurement (node is started with --expose-gc; bun uses Bun.gc(true)).
Memory figures are resident set size in MiB: process.memoryUsage().rss for baseline and retained,
process.resourceUsage().maxRSS for the peak. The upload body is a generated stream (64 KiB chunks), so the
source bytes are not held by the probe itself.
capped.sh runs the node measurement inside a control group: systemd-run --user --scope -p MemoryMax=420M -p MemorySwapMax=0.
Exit status 137 means the kernel killed the process for exceeding the limit (confirmed in the kernel log:
"Memory cgroup out of memory: Killed process ... (MainThread)").
Not run: Cloudflare Workers (workerd, 128 MB isolate limit), Deno, a real network upload through a server adapter,
several uploads at once.
