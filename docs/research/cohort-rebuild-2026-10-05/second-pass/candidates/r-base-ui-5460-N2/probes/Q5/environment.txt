A correction made during the work
  The first version of the probe passed a new `errors` object to the Form on every render. The
  Form then showed the server error again after every accepted keystroke, at both commits, which
  hid the comparison. The probe now creates the object once per case, as an app that keeps server
  errors in state does. Only the corrected runs are saved.
