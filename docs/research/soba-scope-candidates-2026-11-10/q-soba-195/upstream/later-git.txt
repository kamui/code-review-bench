    codeberg: back up Codeberg repositories, and fix CI (#233)
    
    Wires the Codeberg host into soba so it is reachable from a run rather than library-only. Only CODEBERG_TOKEN is required; the API URL is a fixed default.
    
    Registering a provider means three separate registries, and omitting the third compiles and runs but counts the provider as zero, failing with "no providers defined". constants_test.go now asserts they agree in both directions.
    
    Also fixes CI, which had been red since build #716: the live Azure DevOps test cloned a real repository but skipped only when AZURE_DEVOPS_USERNAME was unset, so with that variable set in CI it ran against the live service and failed on the account's state. It is now gated behind SOBA_LIVE_AZURE_DEVOPS_TESTS, matching the existing GitHub and GitLab gates. The CircleCI config moves to version 2.1, version 2 having reached end of life, and GIT_BACKUP_DIR is exported rather than only having its directory created.
