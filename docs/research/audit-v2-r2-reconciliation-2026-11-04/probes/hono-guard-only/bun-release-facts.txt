## PR 31531 body, first paragraph
`.formData()` (on `Response`/`Request`/`Blob`, including `fetch().formData()`) threw "incorrect MIME type/boundary" for a spec-valid Content-Type whose media type or `boundary` attribute name wasn't lowercase — e.g. `Content-Type: Multipart/Form-Data; Boundary=X`. RFC 2045 §5.1 / RFC 7231 §3.1.1.1: the media type and parameter attribute names are case-insensitive (only the boundary *value* is case-sensitive). Node/undici parse these.
