  the clone is checked out at the commit, each patch is applied with `git apply`, the probe file is
  copied to packages/react/src/field/control/zzprobe.test.tsx, then
  VITEST_ENV=<jsdom|chromium> TZ=UTC ./node_modules/.bin/vitest run --maxWorkers=1 \
      --project @base-ui/react packages/react/src/field/control/zzprobe.test.tsx

  nothing. The lines are observations to compare between commits and between patches.
