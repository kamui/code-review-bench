[P2] Reuse cached FormData before converting the body to an ArrayBuffer — `src/utils/body.ts:125-127`. If middleware calls `c.req.formData()` before a handler calls `c.req.parseBody()`, `HonoRequest.arrayBuffer()` reconstructs bytes by serializing the cached FormData as a new multipart body. This code then parses those bytes using the original Content-Type: for multipart the newly generated boundary differs from the original and parsing throws; for URL-encoded requests the multipart bytes are interpreted as URL-encoded data and the returned fields are corrupted. Previously `parseBody()` called `c.req.formData()` and reused the cached form directly, so this breaks existing middleware/handler combinations for ordinary lowercase content types too. A local probe with `foo=bar` reproduced both the malformed URL-encoded result and the multipart exception.
