**[P2] Order argument names without numeric precision collisions.** File: `src/validation/rules/OverlappingFieldsCanBeMergedRule.ts`, line 649.

The old exact-name lookup accepted this order-independent argument set; the new use of sorting introduces the regression for top-level argument names.
