## Finding

### [Low] "creates new stack if original error has no stack" no longer tests a stackless original error

- **File / lines:** `src/error/__tests__/GraphQLError-test.js`, lines 57–64 (the changed fixture is line 58), exercising `src/error/GraphQLError.js` lines 195–209.
- **Evidence:** To satisfy Flow's `?Error` parameter type, the fixture changed from `const original = { message: 'original' };` to `const original = new Error('original');`. A real `Error` always has a string `stack`, so the guard `if (originalError && originalError.stack)` (GraphQLError.js:195) now takes the copy-the-original-stack branch, not the fallback branch (`Error.captureStackTrace` / `Error().stack`) that the test is named for. The test is now in effect a weaker copy of the "uses the stack of an original error" test just above it. I checked this with a scratch probe (`clone-work/scratch/stack-probe.js`) run against the head sources. With the head fixture, `e.stack === original.stack` is `true`, so the stack-copy branch runs. With the base fixture `{ message: 'original' }`, the fallback branch produces a string stack. A simulated mutant that drops the `.stack` check (`if (originalError)`) would set `stack` to `original.stack`. That value is a string under the head fixture, so the test still passes, and `undefined` under the base fixture, so the test failed there. The only other test that reaches the fallback, "has a name, message, and stack trace", passes no `originalError`, so it cannot catch this mutant either.
- **Failure it causes:** The suite no longer covers "an `originalError` is present but has no `stack`". This happens in real use, for example with errors from environments or libraries that strip or never set `stack`, and with error-like objects cast to `Error`. A regression that removes or breaks the `.stack` check would leave `GraphQLError.stack` `undefined` for those errors, and no test would fail. The test title now also misdescribes what it checks. A fixture that keeps Flow happy and still has no stack would restore coverage, for example a `new Error('original')` with `stack` removed or set to `undefined`, or the old object literal cast through `any`.
